数据容器总览

容器类型 写法 是否有序 是否可重复 是否可修改
list（列表） [] 有序 允许 可变
tuple（元组） () 有序 允许 不可变
str（字符串） "" 有序 允许 不可变
set（集合） {} 无序 不允许 可变
dict（字典） {key:value} 有序（Py3.7+） key 不可重复 可变
