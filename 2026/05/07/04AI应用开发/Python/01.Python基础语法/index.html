注释

文件编码注释

文件编码又称“字符编码”，文件编码注释写在 Python 文件的首行，是一种特殊的注释。

它的作用是：指定当前文件的字符编码。

注：在 Python3 中，可以不写文件编码声明，因为 Python3 默认使用 UTF-8 编码。
